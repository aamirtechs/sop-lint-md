sop-lint-md

Lint Markdown SOPs and runbooks for operations content, not style: missing owner, version or review date, overdue reviews, vague steps, steps with no verb, and broken internal links.

View source on GitHub

Run sop-lint-md in your browser

Runs fully in your browser, files never leave your device.

Drag and drop a folder of Markdown SOP files here, or use the folder picker below.

Report



  

    
What it does

    

      
Missing metadata: each required field a file does not declare (owner, version, review date, department) is one finding

      
Overdue reviews flagged with the exact number of days overdue; unparseable review dates flagged as invalid

      
Vague terms such as promptly, as needed and as soon as possible flagged with their line numbers

      
Steps whose first word is not a verb, checked conservatively so good steps are not flagged

      
Broken internal links: relative Markdown links whose target file does not exist

      
Outputs report.md and findings.csv, fully offline

    

  

  

    
Install and usage

    
Requires Node.js 20 or later. There are no dependencies to install.

    
git clone https://github.com/aamirtechs/sop-lint-md.git
cd sop-lint-md
node src/cli.js examples/sops --out-dir out

    
This writes report.md and findings.csv to the output directory. Use --config config.json for custom required fields and vague terms, and --reference-date to judge reviews against a fixed date.
